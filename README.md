# Sea Radar

Карта Дуврської протоки із суднами для заняття.
Програма працює тільки на вашому ноутбуці, в інтернет її не викладено.

---

## Що потрібно

| Що | Навіщо |
| --- | --- |
| Node.js 24 | щоб програма запустилася |
| Інтернет | щоб завантажилася карта |
| Ключ AISStream | щоб бачити справжні судна. Без ключа на карті три демонстраційні |

---

## Налаштування

1. Відкрийте теку проєкту в терміналі.
2. Увімкніть Node 24: `nvm use`
3. Встановіть залежності: `npm ci`
4. Скопіюйте файл `.env.example` і назвіть копію `.env.local`.
5. Відкрийте `.env.local` у редакторі й впишіть ключ `AISSTREAM_API_KEY=ВАШ_КЛЮЧ`.

> Файл `.env.local` нікому не пересилайте. У ньому лежить ваш ключ.

---

## Запуск

1. Виконайте `npm run dev`
2. Відкрийте в браузері `http://localhost:3000`

Якщо змінили ключ, зупиніть програму й запустіть ще раз.

---

## Перевірка

1. Один раз встановіть браузер для тестів: `npx playwright install chromium`
2. Виконайте `npm run verify:full`

Ключ для перевірки не потрібен. Усі рядки в результаті мають бути `PASSED`.

---

## Що варто знати

- **Це знімок, а не стеження.** Кнопка бере позиції на момент натискання. Сама карта не оновлюється.
- **Вибірка неповна.** У знімок потрапляють лише судна, які надіслали позицію за 15 секунд.
- **Невдала спроба нічого не стирає.** На карті лишається те, що було. Окремий рядок пише, що спроба не вдалася і коли.
- **Оновили сторінку — знову демо.** Знімок ніде не зберігається.
