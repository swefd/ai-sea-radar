## 2. Модель стану (B-18)

Два незалежні стани (CR `:23`):

```ts
/** Показаний набір. `snapshot` — лише непорожній успіх, за побудовою. */
type Shown =
  | { kind: 'demo' }
  | { kind: 'snapshot'; response: SnapshotSuccess };

/** Результат останньої спроби. `null` у `done` — відповіді немає або тіло не розібране. */
type Attempt =
  | { kind: 'none' }
  | { kind: 'loading' }
  | { kind: 'done'; response: SnapshotResponse | null };
```

Похідні значення — у рендері, без додаткового стану:

| Значення | Залежить від | Правило |
| --- | --- | --- |
| `vessels` | `shown`, `tick` | `demo` → `fleetAtTick(DEMO_ROUTES, tick, startedAt)`; `snapshot` → `shown.response.vessels` |
| підпис джерела | `shown` | `demo` → `SOURCE_LABELS.demo`; `snapshot` → `snapshotCaption(shown.response)` (формат без змін) |
| рядок спроби | `attempt` | `attemptLine(attempt)`, §3 |
| `running` (демо-таймер) | `shown`, `tick` | `shown.kind === 'demo' && tick < LAST_TICK` — від спроби не залежить |
| кнопка заблокована | `attempt` | `attempt.kind === 'loading'` |

`describe()`, `LoadState`, `LOADING_CAPTION`, `NO_DATA_CAPTION`, `EMPTY_NOTICE`, `NO_VESSELS` і
`hadNonEmptySuccessRef` видаляються: «перший непорожній успіх» — це перехід `shown` з `demo` у
`snapshot`, а назад `shown` не повертається (лише оновленням сторінки).

### Обробник кнопки

```ts
async function handleLoad() {
  setAttempt({ kind: 'loading' });           // набір, підпис і вибір не чіпаються
  const response = await fetchSnapshot();
  setAttempt({ kind: 'done', response });
  if (response?.ok && response.count > 0) {  // тільки непорожній успіх замінює набір
    const ids = new Set(response.vessels.map((vessel) => vessel.id));
    setSelectedVesselId((id) => (id !== null && ids.has(id) ? id : null));
    if (shown.kind === 'demo') setResetViewKey((key) => key + 1);
    setShown({ kind: 'snapshot', response });
  }
}
```

- **Атомарність.** Усі `set*` після `await` в одному синхронному відрізку — React 18+ зводить
  їх в один рендер: карта, картка, підпис і рядок спроби змінюються разом.
- **`shown` із замикання актуальний:** під час запиту кнопка заблокована, а інших записувачів
  `shown` немає.
- **Без злиття** (CR `:30`): новий набір — цілком `response.vessels`; карта прибирає маркери,
  яких у ньому немає (`leaflet-map.tsx:125…131`, без змін).
- **Повернення виду** (CR `:29`) — лише на переході `demo → snapshot`; далі вид не чіпається.
- `fetchSnapshot` не кидає ніколи (`fetch-snapshot.ts:9`), тож кнопка не лишається
  заблокованою.

### Не змінюються

`fetch-snapshot.ts`, `snapshot-caption.ts` (включно з `NO_SERVER_RESPONSE`), `leaflet-map.tsx`,
`dover-strait-map.tsx`, усе в `src/entities/`, `src/shared/`, `src/_app/`, `app/`.
