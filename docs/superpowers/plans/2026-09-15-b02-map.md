# B-02. Карта району — план реалізації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Показати карту Дуврської протоки на всю доступну область сторінки: Leaflet підключений тільки на клієнті, шар OpenStreetMap з атрибуцією, район і початковий вид — з єдиного файлу конфігурації.

**Architecture:** Маршрут `app/page.tsx` стає реекспортом зрізу FSD `src/_pages/home`. Сторінка — серверний компонент; він рендерить тонкий клієнтський посередник, який єдиний має право завантажити модуль Leaflet, і робить це через `next/dynamic` з `ssr: false`. Значення району, виду й тайлів живуть у `src/shared/config` і нікуди більше не дублюються.

**Tech Stack:** Node.js 24 · TypeScript 6.0.3 `strict` · Next.js 16.3.5 (App Router) · React 19.3.0 · Leaflet 1.9.4 · CSS Modules.

**Spec:** `docs/superpowers/specs/2026-09-15-b02-map-design.md`

## Global Constraints

Кожне завдання нижче неявно включає всі ці вимоги.

- **Завдання-джерело:** `docs/tasks/SPRINT-01.md:28` (B-02) і `docs/tasks/PROJECT_BRIEF.md:45` (US-01). Читати файли, не переказ.
- **Node 24.** У `.nvmrc` записано `24`. Кожна команда нижче виконується з префіксом `PATH="$HOME/.nvm/versions/node/v24.21.0/bin:$PATH"`, бо неінтерактивна оболонка не бачить `nvm`. В інтерактивному терміналі рівноцінно: `nvm use`, далі звичайний `npm`.
- **Залежності — рівно дві нові й жодної більше:** `leaflet@1.9.4` (dependency) і `@types/leaflet@1.9.22` (devDependency). Версії точні, без `^`, як у B-01. Ні `react-leaflet`, ні `geodesy`, ні `ws`, ні жодного тестового фреймворка.
- **Тестового раннера цього тижня тут немає.** Playwright приходить у B-07. Доказова база B-02: `npm run build` (машинна) і браузер (візуальна). Не додавати Vitest, Jest чи будь-що інше, щоб «було чим перевірити».
- **Значення — літералами зі `SPRINT-01.md:16`, кожне в одному місці:** район `south: 50.75, west: 0.95, north: 51.25, east: 1.95`; центр `lat: 51.0, lon: 1.45`; `zoom: 10`; тайли `https://tile.openstreetmap.org/{z}/{x}/{y}.png`; атрибуція `© OpenStreetMap contributors`.
- **Leaflet — тільки на клієнті.** Жоден серверний компонент не імпортує модуль карти ані прямо, ані транзитивно.
- **Запуск:** `http://127.0.0.1:3000`, тільки loopback (`npm run dev` уже містить `-H 127.0.0.1`).
- **`reference/` не імпортується ніколи** — ні в коді, ні в типах. Файли під `reference/` не редагуються.
- **Секрети не читаємо й не виводимо.** У B-02 їх узагалі немає в дотичних файлах.
- **Поза межами:** судна, значки, картка, панель, підпис джерела, кнопка, стан, `metadata`, `maxBounds`, `maxZoom`, `ResizeObserver`, обгортки над Leaflet, заготовки під справжні дані, теки «на майбутнє».

- [ ] **Step 2: Створити `src/_pages/home/ui/leaflet-map.tsx`**

```tsx
'use client';

import { useEffect, useRef } from 'react';
import * as L from 'leaflet';

import { INITIAL_VIEW, OSM_TILE_LAYER } from '@/shared/config';

import 'leaflet/dist/leaflet.css';
import styles from './leaflet-map.module.css';

export function LeafletMap() {
  const containerRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const container = containerRef.current;
    if (container === null) {
      return;
    }

    const map = L.map(container).setView(
      [INITIAL_VIEW.center.lat, INITIAL_VIEW.center.lon],
      INITIAL_VIEW.zoom,
    );

    L.tileLayer(OSM_TILE_LAYER.urlTemplate, {
      attribution: OSM_TILE_LAYER.attribution,
    }).addTo(map);

    return () => {
      map.remove();
    };
  }, []);

  return <div ref={containerRef} className={styles.map} />;
}
```

Три речі тут не випадкові:

1. `import * as L`, а не `import L from 'leaflet'`. Пакет `leaflet@1.9.4` віддає лише UMD-збірку (`main`, без полів `module` й `exports`), а `@types/leaflet` описує іменовані експорти й `export as namespace L`, без `default`. Іменований простір імен коректний і на рівні типів, і в рантаймі.
2. Ініціалізація синхронна, прибирання — `map.remove()`. У StrictMode ефект виконується двічі; без `remove()` другий прохід падає на «Map container is already initialized».
3. `leaflet/dist/leaflet.css` імпортується поруч із бібліотекою. Забутий CSS — друга класична причина сірого прямокутника.
