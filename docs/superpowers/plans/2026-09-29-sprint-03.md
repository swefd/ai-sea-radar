Правила (SPRINT-02:25, :27; регістр полів — ЗІ ЗРАЗКА):
- `raw.MessageType !== 'PositionReport'` або не об'єкт → `null` (включно з `SubscriptionConfirmation`).
- `id` ← `MetaData.MMSI`: число (скінченне ціле > 0) → `String(n)`; рядок після trim непорожній → він; інакше (відсутній, `""`, `"   "`, `0`?) → `null`. MMSI `0` — непорожній, лишається `"0"`: правило каже лише «непорожній».
- `name` ← `MetaData.ShipName`: рядок → trim → порожній → `null`; не рядок → `null`.
- `lat`, `lon` ← `Message.PositionReport.Latitude` / `.Longitude`; мусять бути `typeof === 'number'` і скінченні; `lat` в [-90, 90], `lon` в [-180, 180]; `lat === 91` або `lon === 181` → відкинути (91 поза [-90,90] і так; 181 поза [-180,180] і так — окремої гілки не треба, але окремий тест є). Інакше → `null` (судна немає).
- `timestamp` ← `parseAisTimeUtc(MetaData.time_utc)`; `null` → відкинути.
- `speedKnots` ← `Sog`: число, скінченне, в [0, 102.2] → воно; інакше `null` (позиція приймається).
- `courseDeg` ← `Cog`: число, скінченне, `>= 0 && < 360` → воно; інакше `null`.
- `source: 'aisstream'`.

`parseAisTimeUtc`: регулярний вираз
`/^(\d{4})-(\d{2})-(\d{2}) (\d{2}):(\d{2}):(\d{2})(?:\.(\d{1,9}))? ([+-])(\d{2})(\d{2})(?: [A-Za-z]+)?$/`.
Дріб обрізається (не округлюється) до 3 цифр і доповнюється нулями. `Date.UTC(...)` мінус зсув; потім **перевірка відсутності перенесення**: компоненти, зібрані назад з `new Date(utcMs + offsetMs)` через `getUTC*`, мусять збігтися з розібраними (інакше `null`). Повертає `new Date(ms).toISOString()`.

### Task 2: The collector (B-12 plus B-15 tests)

**Files:**
- Modify: `src/shared/api/aisstream/collector.ts`. The types are already there: add the body of `collect` and do not change the type shapes.
- Test: `tests/unit/aisstream-collector.spec.ts`

**Interfaces:**
- Consumes:
  - `Connect`, `SocketHandle`, `TimerId`, `ReadErrorCode` from `./transport`;
  - `buildSubscription(apiKey)` from `./subscription`;
  - `Collectable`, `CollectOptions<T>`, `CollectResult<T>`, already in `collector.ts`.
- Produces: `export function collect<T extends Collectable>(options: CollectOptions<T>): Promise<CollectResult<T>>`.

The settle-once mechanics follow `reader.ts`; read all of it first:
- `settle` with a single guard;
- `subscribe()` that survives a synchronous `onOpen`;
- re-closing the handle after `connect` returns;
- the `if (!settled)` guard around the timer.

**Differences from the reader. Each one is a requirement:**
- **`onMessage`:**
  - If `JSON.parse` throws, **skip** the message; do not settle with `internal`. Collection is a stream, and one broken frame must not kill the snapshot.
  - If `toItem(raw) === null`, skip it.
- **Storage:** a `Map<string, T>`.
  - A new `item` whose `id` is not in the map is added. The limit settles the attempt as soon as it is reached, so a 101st id is never accepted.
  - An `item` whose `id` is already present replaces the old object **whole**, and only if `Date.parse(item.timestamp) > Date.parse(existing.timestamp)`. The comparison is strict: on equal timestamps the first one stays.
- **Limit:** after inserting a new id, if `map.size === limit`, call `settle({ kind: 'done', items: [...map.values()], reason: 'limit_reached', finishedAt: now() })`.
- **Timer:**
  - if `subscribed`, settle with `done` and `reason: 'window_elapsed'` (the set may be empty);
  - otherwise `error connect_failed`.
- **`onError`:**
  - **before open** (`!opened`): `connect_failed`. SPRINT-02:29 says a socket error before open is `connect_failed` immediately; the reader answers `provider_error` here, which is a known divergence;
  - after open: `provider_error`.
  - Neither returns a partial set.
- **`onClose`:** `subscribed ? 'disconnected' : 'connect_failed'`.
- **Cancellation** (`signal`): `error internal`. This was the human's decision; see "Rulings made while planning".
- **`finishedAt`:** `now()` at the moment of settling, on every branch.

// (position-report.spec.ts). Збирачу досить знати id і timestamp.

const KEY = 'EXAMPLE-KEY-NOT-A-REAL-ONE';
const T0 = 1767268800000; // 2026-01-01T12:00:00.000Z

type Item = { id: string; timestamp: string; p: string; name: string | null };

function stand() {
  let handlers: SocketHandlers | null = null;
  const sent: string[] = [];
  let closes = 0;
  const timers = new Map<number, () => void>();
  let nextId = 1;
  let clock = T0;

  const connect: Connect = (h) => {
    handlers = h;
    return { send: (text) => sent.push(text), close: () => { closes += 1; } };
  };

  const stand = {
    connect,
    sent,
    get closes() { return closes; },
    get handlers() {
      if (handlers === null) throw new Error('connect ще не викликано');
      return handlers;
    },
    setTimer: (fn: () => void, _ms: number) => {
      const id = nextId++;
      timers.set(id, fn);
      return id as unknown as ReturnType<typeof setTimeout>;
    },
    clearTimer: (id: ReturnType<typeof setTimeout>) => { timers.delete(id as unknown as number); },
    fireTimers() { for (const fn of [...timers.values()]) fn(); },
    get liveTimers() { return timers.size; },
    now: () => clock,
    advance(ms: number) { clock += ms; },
    /** Подає повідомлення JSON-текстом, як це робить сокет. */
    send(message: object) { stand.handlers.onMessage(JSON.stringify(message)); },
  };
  return stand;
}

function toItem(raw: unknown): Item | null {
  const r = raw as { id?: unknown; t?: unknown; p?: unknown; name?: string | null; skip?: boolean };
  if (r.skip === true || typeof r.id !== 'string' || typeof r.t !== 'string' || typeof r.p !== 'string') {
    return null;
  }
  return { id: r.id, timestamp: r.t, p: r.p, name: r.name ?? null };
}

function run(s: ReturnType<typeof stand>, opts: { limit?: number; signal?: AbortSignal } = {}) {
  return collect<Item>({
    connect: s.connect,
    apiKey: KEY,
    windowMs: 15_000,
    limit: opts.limit ?? 100,
    toItem,
    now: s.now,
    setTimer: s.setTimer,
    clearTimer: s.clearTimer,
    signal: opts.signal,
  });
}

/** Після будь-якого результату: з'єднання закрите рівно раз, таймерів немає (SPRINT-03:58). */
function expectReleased(s: ReturnType<typeof stand>) {
  expect(s.closes).toBe(1);
  expect(s.liveTimers).toBe(0);
}
